# Тропа для компьютера (Windows) — план

Составлено 30.10.2026. Ничего из этого ещё не начато; телефон для работы не нужен.

## Что переносится без изменений
Около 2700 строк без единого `import android` — вся логика:

| Файл | Что делает |
|---|---|
| `sub/LinkParser.kt`, `sub/SubscriptionParser.kt`, `sub/XrayJson.kt` | разбор подписок и ссылок |
| `core/XrayConfig.kt`, `core/XrayOutbound.kt`, `core/ProviderRouting.kt` | конфиг Xray, маршруты провайдера, цепочки |
| `core/MihomoConfig.kt`, `core/MihomoApi.kt`, `core/XrayApi.kt`, `core/CoreApi.kt` | второе ядро, статистика ядра |
| `ui/Names.kt` | страны, LTE, операторы, лимиты |
| `core/Pairing.kt` | QR-передача подписок (на ПК — тоже «Отправить на ТВ») |
| `data/Models.kt`, `core/Ping.kt`, `core/ProxyHttp.kt` | модели, проверка серверов |

Почти без правок: `SubscriptionFetcher.kt` (4 импорта Android: HWID и User-Agent), `Store.kt` (путь к файлу),
`Quality.kt` (путь к ядру).

## Устройство
1. Вынести файлы выше в модуль `shared` (Kotlin/JVM, `org.json` + SnakeYAML как зависимости).
   Android-приложение подключает его так же, как сейчас — тесты (29 шт.) переезжают туда же.
2. Модуль `desktop` — Compose Multiplatform for Desktop: тот же стиль (Onest, палитра), те же экраны
   «Главная / Серверы / Маршруты / Настройки». Значок в трее: подключить/отключить, страна.
3. Ядро — официальный `Xray-windows-64.zip` с релизов XTLS (сверка SHA-256, как в Android-сборке).
4. Два режима:
   - **Системный прокси** (по умолчанию, без прав администратора): локальный HTTP/SOCKS-вход Xray
     **с паролем** и случайным портом, Windows-прокси на него. Браузеры и большинство программ.
   - **Весь трафик (TUN)** — Xray `tun`-вход + wintun.dll, нужны права администратора (как у Happ).
     «Напрямую» для программ — по имени процесса (`process` в правилах Xray на Windows).
5. Автообновление — тот же `update.json` (ключ `windows` рядом с `arm64-v8a`), установщик MSI/EXE,
   подпись кода — отдельный вопрос (без сертификата Windows SmartScreen предупреждает).
6. Сборка установщика: `jpackage` (входит в JDK) → MSI.

## Порядок
1. Модуль `shared` + перенос тестов (полдня, телефон не нужен).
2. Окно с подписками и выбором сервера, режим «системный прокси» (день).
3. TUN-режим и трей (день).
4. Установщик и обновления.
